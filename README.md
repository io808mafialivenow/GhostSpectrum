# GhostSpectrum

GhostSpectrum is a modernized, feature-extended fork and revival of eDEX-UI for sci-fi terminal dashboard workflows.

This repository preserves the upstream eDEX-UI heritage while introducing a fresh, cross-platform GhostSpectrum identity for telemetry dashboards, Android tooling workflows, hardware repair automation, and system utility operations.

Important attribution and licensing:
- Upstream project: GitSquared/eDEX-UI
- Upstream license: GPL-3.0-or-later

Current scaffold status:
- Initial app shell created for Electron + HUD dashboard
- Core project structure started under `src/`
- Packaging and cross-platform rebuild scripts prepared in `package.json`
- Installer bootstrap scripts included for Linux and Windows

Planned GhostSpectrum modules:
- USB-HID / Rubber Ducky payload simulation panel
- Android 16+ toolchain integration and platform-tools sync flow
- Samsung Heimdall / ADB / Fastboot repair helpers
- Cross-platform installation tooling for `ghost` terminal aliasing

The project is intentionally designed as a clean modern fork baseline and can be extended toward the full eDEX-UI-style terminal emulator and telemetry workload.
